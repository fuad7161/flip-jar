# Flip Jar

A one-thumb physics merge game with a twist: flip the whole jar upside down.
See `../Knowledge.md` for the full brief.

## Run on desktop
1. Install Godot 4.7 (standard build, not .NET) from https://godotengine.org/download
2. Open this folder (`game/`) in Godot, or run `godot --path game` from the project root.
3. Mouse emulates touch: drag to aim, release to drop. Click FLIP to flip the jar.

## Files
- `scenes/menu.tscn`, `scripts/menu.gd`   main menu: LEVEL / DAILY, then LEVELS / SETTINGS (sound, music, vibration, themes popup) / EXIT
- `scripts/icon_button.gd`, `scripts/icons.gd`   candy buttons with a drawn icon and a small caption; the icon set
- `scenes/levels.tscn`, `scripts/levels_screen.gd`   level select: best stars and time per level, locked levels
- `scripts/levels.gd`    the 60-level ladder (goal, time limit, jar settings per level), star rules, daily settings
- `scripts/level_bar.gd` level HUD under the jar: GOAL tube on top fills with score, TIME tube below drains, star chips at the cut-offs
- `scripts/star_row.gd`  the animated 3-star row on the result screen
- `scenes/game.tscn`, `scripts/game.gd`   game loop: jar, drop, merge, flip, overflow, score, juice, result screen
- `scripts/piece.gd`     one jelly piece: droplet stretch in flight, squash and wobble on impact, merge contacts
- `scripts/tiers.gd`     tier sizes, names and the three color palettes; the face drawing
- `scripts/fx.gd`        merge ring, confetti burst, floating score
- `scripts/save.gd`      autoload: local save (user://save.json), daily attempts, streaks, settings
- `scripts/sfx.gd`       autoload: sound pool
- `scripts/preview.gd`   "next piece" preview in the UI layer
- `audio/*.wav`          generated by `tools/gen_sfx.py` (no external dependencies)
- `icon/*`               generated by `tools/gen_icon.py` plus the project SVG icon
- `export_presets.cfg`   Android export preset (portrait, arm64 + armv7, immersive)

## Headless smoke test
Plays a full daily run (drops, two flips while holding a piece, overflow, result screen, restart)
and checks the save logic. Takes about two minutes of real time.
```
godot --headless --path game --script res://tests/smoke.gd
```
Prints `SMOKE OK` and exits 0 on success. Add `--fixed-fps 60` to run it as fast as the CPU allows.

## Level tuning bot
Plays levels at a human-like pace (aims at matching pieces) and prints clear times and stars:
```
godot --headless --fixed-fps 60 --path game --script res://tests/level_sim.gd -- 1,10,30,60 1.2 3
```
Arguments: level list, seconds between drops, runs per level. Tune the curve in `scripts/levels.gd`.

## Regenerate assets
```
python3 game/tools/gen_sfx.py
python3 game/tools/gen_icon.py
```

## Build the Android APK (no Android Studio needed)

**Option A, on GitHub's servers (recommended for a slow PC).** Nothing heavy is installed locally.
1. Create a free GitHub repository and push this project (see the commands at the project root README section below).
2. GitHub runs `.github/workflows/android.yml` on every push to `main`. It takes about 10 minutes.
3. Open the repository's Actions tab, click the latest run, and download `flipjar-debug-apk` under Artifacts.
4. Copy the APK to the phone and open it, or run `adb install -r flipjar-debug.apk`.

**Option B, locally with the command-line SDK only.** About 1.3 GB of downloads, no IDE.
```
bash game/tools/setup_android_local.sh   # once: SDK tools, export templates, debug keystore, Godot settings
bash game/tools/build_apk.sh             # every build: writes export/flipjar-debug.apk
```
The same settings let you export from the Godot editor too: Project > Export > Android.

**For the Play Store** run `bash game/tools/make_release_keystore.sh` once, add the three secrets it
prints to the GitHub repository, then start the "Build Play Store AAB" workflow from the Actions tab
(or push a tag such as `v0.1.0`). Download `flipjar-release-aab` and upload it in Play Console.
The full publishing checklist is in `../store/PUBLISHING.md`.
